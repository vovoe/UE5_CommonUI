# Unreal Engine 5 project with Common UI
This project demonstrates the basic use of the Common UI plugin to create a responsive and scalable user interface in Unreal Engine 5.

Features.
Responsive UI: The interface automatically adjusts to different platforms, including PCs, consoles, and mobile devices.
Support for multiple input devices: Common UI allows you to integrate support for keyboard, mouse, gamepad, and touch.
Easy customization: Easily create and customize UI templates using a slot system.
Quick start: A ready-made framework for adding new UI elements such as menus, buttons, and HUDs.
